# Mímir 不变量与测试门禁（v1.0 草案）

> **日期**：2026-11-19  
> **适用范围**：`mimir_v8`（1.7.x → 1.9.x → 2.x 演进期间）  
> **目标**：把护栈变成可执行门禁（CI / 回归 / 故障注入 / 幂等 / 迁移），防止治理稀释与静默降级。

---

## 1. 核心不变量（不可违背）

| ID | 不变量 | 破坏后果 | 验证方式 |
|----|--------|----------|----------|
| INV-01 | **事件账本不可缺失**：凡声称删除/归档/衰减，必须先写可追溯账本（如 `memory_events`/tombstone 等价记录）再执行；账本写失败则不删 | 数据不可追溯、误删不可恢复 | 故障注入：账本写入失败时断言目标仍存活；审计事件存在 |
| INV-02 | **不静默降级**：召回/摄入/投影失败必须显式暴露 verdict/reason（found/not_found/degraded），禁止“假空”“假成功” | 质量假象、排障失真 | 单元/集成：构造通道失败断言 degraded + reason；API 响应含 verdict |
| INV-03 | **幂等可重放**：对同一 `idempotency_key`（或等价请求指纹）重试不得产生重复副作用（重复 fact/source/candidate/feedback） | 数据污染、计数膨胀 | 幂等测试：同 key 连续请求 N 次，断言唯一记录与一致响应 |
| INV-04 | **权限与归属不可绕过**：读/写/摄入/消费必须受 `owner_principal`、scope/ACL 约束；跨域/跨库默认拒绝 | 越权、串库、数据泄露 | 权限矩阵测试：异 principal 读写断言拒绝/过滤；审计拒绝事件 |
| INV-05 | **治理链路不被自动化绕过**：自动记忆/摄入产物默认进入候选或可审计暂存；`UPDATE/DELETE` 永不静默自动生效（除非显式翻案并记录 ADR） | 错误记忆固化、审计失效 | 管线测试：SessionEnd/STN 结晶后断言进入 candidate/staging，非 canonical fact |
| INV-06 | **谱系/时态语义一致**：取代/修订/撤回必须通过唯一权威谱系表达（目标：`fact_supersessions`），查询默认返回现行视图且可追溯历史 | 历史语义混乱、双真相源 | 迁移+查询测试：supersede 后默认命中现行；`include_superseded` 可见旧版与链路 |
| INV-07 | **适配器契约向后兼容（同 major）**：Contract v1 必填字段/语义在同 major 内不得破坏性变更；新增字段须可选且有默认 | 多 Agent 接入脆弱、升级中断 | 契约快照/JSON Schema 校验；旧 payload 兼容性测试 |
| INV-08 | **凭据与敏感配置不泄露**：安装器/适配器不得读取或回显密钥、token、sealed credential；合并写入仅限声明字段 | 凭据外泄 | 静态扫描 + 集成测试：模拟含密钥配置，断言输出/日志/补丁不含密钥 |

## 2. 测试门禁矩阵

### 2.1 CI 必过（阻塞合并）

| 类别 | 用例要求 | 失败处理 |
|------|----------|----------|
| 单元/契约 | Adapter Contract v1 schema 校验；identity/trace/verdict 枚举与必填字段 | 阻断 |
| 幂等 | ingest/write/feedback 对同 idempotency_key 重放无副作用 | 阻断 |
| 权限 | owner/ACL/域隔离正反例 | 阻断 |
| 召回判语 | found/not_found/degraded 路径覆盖；degraded 传导不被吞没 | 阻断 |
| 迁移 | additive migration 前进可用；关键表/列存在性；旧数据可读 | 阻断 |
| 现有回归 | `eval_suite.py` GOLDEN_FLOORS 不低于当前基线（`hit_rate@3 ≥ 0.65`，`hit_rate@10 ≥ 0.83`） | 阻断（按协议，非零退出） |

### 2.2 故障注入（版本门槛/定期）

| 场景 | 注入方式 | 期望 |
|------|----------|------|
| 账本写失败后删除 | mock/event store write error | 不删、不静默成功，报错可观测 |
| 向量/FTS/图通道部分失效 | 禁用单通道 | degraded verdict + 可用通道结果（如有） |
| 投影器落后/死信 | 人为制造 pending/dead_letter | `/v8/ready` 或状态面可见，不假装 ready |
| 重复消息/乱序投递 | 同消息重放、乱序 | 幂等去重，状态一致 |

### 2.3 迁移与回滚演练

- **前进**：在生产镜像/快照上演练 additive migration；验证读写与关键查询。
- **回滚**：定义“代码回滚 + schema 兼容窗口”策略；对破坏性变更必须提供逆向脚本或明确不可回滚声明（ADR）。
- **双写/影子期**：对语义收敛项（如谱系统一、热度读闭环）先影子观测再切主路径。

## 3. 进/出门槛（与路线图对齐）

| 阶段 | 进入门槛 | 退出门槛（可证伪） |
|------|----------|--------------------|
| 1.9.0 接入+消费 | P0 真值冻结、Contract v1 草案、关键决策拍板 | L1 适配可用（至少一主路径）；identity/trace 贯通；双池路由最小可用；INV-01~08 无回归 |
| 1.10 消费+韧性 | 1.9.0 验收通过；回滚/灰度方案就绪 | 消费工具可用；降级可观测；迁移演练通过；SLO/告警基线建立 |
| 2.0 双时态预研/实现 | 语义词汇表与 ADR 定稿；additive 字段已验证 | 现行/历史查询语义明确；不破坏既有查询契约；全量回归+迁移演练通过 |

---

## 4. 特性开关与灰度（最小要求）

- 新行为默认 **off** 或 **shadow**，经观测达标后再启用。
- 每个开关需声明：作用域（全局/按 adapter/按 principal）、默认值、回滚方式、观测指标。
- 热度影响排序、自动结晶策略等高风险项必须支持一键回退到“仅观测/旧路径”。

---

## 5. 维护规则

- 新增跨模块能力必须补：不变量影响评估 + 至少一条自动化验证。
- 任何“例外直转/绕过治理”必须 ADR 记录，并附补偿控制与审计字段。
- 本文件随版本演进更新；删除/弱化不变量需单独评审。
