## semver 承诺条款（即刻生效，不等 1.0 发布）

1. **次版本**（1.1/1.2）：加功能、加表、加响应字段——**加法不删法**
2. **大版本**（2.0）：破坏性变更（改表结构语义/删 API/改响应形状）——必须在计划卡显式标注
3. **补丁版本**（1.0.1）：修 bug 不动面
4. v15 施工起即养习惯：任何改面动作先问「这是加法还是删法」
